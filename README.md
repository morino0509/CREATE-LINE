# CREATE LINE

ホテルイベントを中心に、企画・空間演出・イベント運営を手がける架空のイベントプロデュース会社「CREATE LINE」のコーポレートサイトです。

企業のコンセプトや事業内容を整理し、ブランドの世界観が伝わるWebサイトを目指して制作しました。

## プロジェクト概要

- **制作期間**：約1.5か月
- **制作目的**：自主制作（ポートフォリオ用）
- **担当範囲**：企画・情報設計・デザイン・コーディング
- **制作物**：架空のイベントプロデュース会社のコーポレートサイト

## 制作背景・目的

架空のイベント制作会社を設定し、企業のブランドイメージや事業内容をWebサイトで表現することを目的に制作しました。

企業のコンセプトやターゲットを想定したうえで、各ページの役割や掲載する情報を整理し、サイト全体で一貫した世界観を伝えられるよう意識しました。

## デザインコンセプト

**Luxury × Experience**

ホテルイベントを中心に扱う企業を想定し、上質さと華やかさを兼ね備えたデザインを目指しました。

写真や映像を効果的に取り入れ、余白やタイポグラフィ、配色にもこだわることで、企業の持つ世界観やイベントの特別感が伝わるビジュアルに仕上げています。

## 制作工程

1. **企画・情報設計**：企業コンセプトやターゲットを設定し、サイト全体の構成を検討
2. **ワイヤーフレーム作成**：各ページの情報配置やレイアウトを設計
3. **デザイン制作**：Figmaでデザインカンプを作成
4. **コーディング**：HTML・CSS・JavaScript・jQueryを使用して実装

※現在も制作途中のため、今後、動作確認や表示調整、コードの最適化を進める予定です。

## 制作ページ

- **TOP**：企業コンセプトや事業内容、実績などを紹介
- **ABOUT**：企業理念や会社概要を紹介
- **JOBS**：事業内容やサービスを紹介
- **RECRUIT**：採用情報を紹介
- **ENTRY**：エントリーフォーム

## 工夫したポイント

- **情報設計**：企業の特徴や事業内容が伝わるよう、ページごとの役割と情報の優先順位を整理
- **世界観の統一**：配色・フォント・写真・余白などを調整し、サイト全体で一貫したブランドイメージを表現
- **ビジュアル表現**：写真や映像を効果的に取り入れ、イベントの臨場感や特別感を演出
- **動きのあるUI**：Slickを使用したスライダーを実装し、制作実績を視覚的に見せる構成に
- **レスポンシブ対応**：PC・スマートフォンそれぞれの画面サイズに合わせてレイアウトを調整

## 今後の改善予定

現在も制作を進めており、以下の点を中心に改善予定です。

- 各ページのコンテンツや情報の充実
- レスポンシブ表示の調整
- アニメーションや操作性の改善
- コードの整理・最適化
