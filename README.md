# CREATE LINE

イベント制作会社「CREATE LINE」を想定した、架空のコーポレート・採用サイトです。

## プロジェクト概要

ホテルイベントを中心に、企画・空間デザイン・イベント運営を手がける会社を想定して制作しています。

## 制作目的
